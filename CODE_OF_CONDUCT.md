# Code of Conduct

This project follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

In short: be decent to each other. Assume the person on the other side is trying to do good
work with incomplete information, because that is usually true. Critique the code, the design
or the claim — not the person making it.

Report unacceptable behaviour to **conduct@hypersurgery.dev**. Reports are handled by the
maintainers listed in [MAINTAINERS.md](MAINTAINERS.md); if a report concerns a maintainer, it
can be sent to the CNCF Code of Conduct Committee at conduct@cncf.io instead.
