Products

One operator per problem nobody owns.

Each one keeps an inventory of one part of your infrastructure, names an owner for every item in it and says what is wrong — in Kubernetes objects, Prometheus metrics and a Grafana dashboard. Each starts read-only.

Subnet Operator

Cloud network inventory, maintained by the cloud itself.

Every VPC and subnet in AWS, Google Cloud and Azure, discovered from resource tags, with its owner, free addresses, missing tags and overlaps. If you opt in, it also allocates subnets on request.

How we build

The same rules for every operator.

So that the second one is as safe to install on day one as the first.

Read-only first

Each operator starts by looking. Anything that writes is a separate, opt-in layer with its own permissions, and nothing deletes what it did not create.

Kubernetes-native

The inventory is custom resources with status conditions and owners: kubectl, GitOps and RBAC work on it as on anything else in the cluster.

Observable out of the box

Prometheus metrics, alerting rules with runbooks and a Grafana dashboard ship with every chart, so a finding reaches a person, not only a status field.

Open and checkable

Apache-2.0, developed in the open, with CI, security scans and OpenSSF Scorecard published — and a plain statement of what has not been proven yet.
